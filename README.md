# Autonomous Engineering Worker

A lightweight autonomous AI worker that translates a business-oriented software request into a verified technical outcome.

## Core Loop

Goal -> Understand -> Plan -> Execute -> Observe -> Adapt -> Verify -> Complete

## Stack

- Python
- FastAPI
- Streamlit
- LangGraph
- Ollama
- Qwen
- Redis
- SQLite
- ChromaDB
- Git
- Docker
- PyTest
- OpenTelemetry

## Architecture

The worker receives a business objective, investigates a software repository, selects appropriate tools, executes changes, observes results, recovers from failures where possible, and independently verifies the requested outcome.
